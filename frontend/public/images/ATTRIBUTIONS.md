# Image attributions

Every photograph in `frontend/public/images` is listed here. Each one was taken
from its Wikimedia Commons file page, where its licence was checked on
4 October 2026. The files are stored in this repository and are never loaded
from another website.

The same details are in `frontend/src/lib/images.ts`, which the pages and the
Image Credits page (`/image-credits`) read. When an image is added, changed or
removed, update this file and that one together.

Rules:

- An image is added only when its own file page states a licence that permits
  reuse. "Publicly visible" is not a licence.
- No photograph is taken from the NCPOR website. Its pages are used as a source
  of facts only.
- No portrait of a scientist is used. Profiles show initials.
- The files were resized and compressed. Nothing else was changed. Files under a
  ShareAlike licence stay under that same licence.

## Images removed in this change

These four files had no recorded source or licence, so they were deleted:

- `datasets/glacier.jpg`

## Places with no photograph, on purpose

- **Bharati station:** no photograph with a clear licence was found. The only
  candidate on Wikimedia Commons is marked public domain with an unknown author,
  which is not clear enough. The station is shown with its facts and its place
  on the Polar Map, where its details say that no licensed photograph is held.
- **Himadri station:** no licensed photograph of the station building was found.
  The Ny-Ålesund photograph above shows the settlement it stands in.
- **Datasets, publications, documents, search, Data Lab and admin pages:** these
  show data and records, not decorative photographs.

## Map data on the Polar Map

The globe on `/map` is not a photograph. It is drawn in the browser by MapLibre
GL JS (BSD 3-Clause) from the vector tiles of OpenFreeMap, which follow the
OpenMapTiles schema and are made from OpenStreetMap data. No API key is used.
The credit "OpenFreeMap, © OpenMapTiles, © OpenStreetMap contributors" is shown
on the globe and under it.
